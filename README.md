# 파형 영상 만들기

음원 파일을 올리면 파형 애니메이션을 만들어 MP4로 저장하는 웹앱입니다. 모든 처리는 브라우저 안에서 이뤄지고 파일은 서버로 전송되지 않습니다.

## 기능

- 파형 종류: 막대, 미러 막대, 라인, 원형, 점
- 색(단색, 그라데이션), 위치, 크기, 굵기, 간격, 민감도, 빛 번짐 조절
- 비율 16:9, 9:16, 1:1과 720p, 1080p, 30fps, 60fps
- 배경 색, 이미지, 영상, 블러
- 제목·아티스트 표시 선택, 앨범 아트, 로고(모서리 기준 배치), 진행바
- 음원 포함 여부 선택
- 출력 형식 선택: 일반 MP4, 투명 MOV(알파 포함 한 파일, PCM 오디오), 투명 PNG 시퀀스 ZIP(audio.wav 포함), 합성용 단색 배경 MP4(검정 또는 초록)
- 저음 비트에 반응하는 크기 펄스와 색 변화
- 구간 자르기와 페이드 인/아웃
- 기본 프리셋 13종(미리보기 포함), 내 프리셋 저장, JSON 내보내기와 가져오기

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm test        # 단위 테스트 (ffmpeg가 있으면 MOV 디코딩 검증도 함께 실행, FFMPEG_PATH로 경로 지정 가능)
npm run lint
npm run build
```

## 브라우저 지원

MP4 내보내기는 WebCodecs를 사용합니다. 최신 Chrome과 Edge를 권장하고, 다른 브라우저에서는 H.264 또는 AAC 인코딩 지원 여부에 따라 내보내기가 제한될 수 있습니다. 미지원 시 화면에 안내가 표시됩니다.

## 구조

- `lib/audio.ts` 디코딩, FFT, 프레임별 분석
- `lib/render.ts` 캔버스 렌더러
- `lib/export.ts` MP4 내보내기 파이프라인
- `lib/player.ts` 미리보기 재생
- `lib/settings.ts` 설정 타입, 기본값, 프리셋
- `components/` 화면 (탭 기반 설정 패널, 공용 입력 컴포넌트)
